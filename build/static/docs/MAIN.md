# Документация платформы NETO

Настоящий комплект документов описывает продуктовую логику, функциональное назначение модулей и типовые сценарии использования платформы NETO. NETO — это сервис автоматизации коммуникаций с клиентами на базе ИИ-ассистента: голосовые звонки, текстовый чат-виджет и встроенная лёгкая CRM.

## Назначение документации

Материалы предназначены для:

- ознакомления с принципами работы платформы до начала её использования;
- понимания того, какие задачи решает каждый модуль интерфейса;
- оценки применимости NETO под конкретные бизнес-процессы;
- подготовки к внедрению и настройке системы.

## Что содержит документация

1. **Описание продуктовой логики** — какие принципы заложены в поведение системы и ИИ-ассистента, какие ограничения приняты намеренно.
2. **Функциональное назначение каждой вкладки** — что видит пользователь, какой смысл несёт каждый раздел, какие действия доступны.
3. **Типовые сценарии использования** — примеры реальных путей пользователя от регистрации до получения результата.
4. **Практическое руководство** — пошаговые инструкции по настройке и эксплуатации.
5. **Справочные материалы** — безопасность, тарифы, интеграции, ответы на частые вопросы.
6. **Структура и статус проекта** — текущее состояние платформы и планируемые этапы развития.

## Чего в документации нет

- Технических спецификаций архитектуры и исходного кода.
- Инструкций по программированию и развёртыванию серверной части.
- Маркетинговых обещаний, не подтверждённых функционалом прототипа.

Документация сфокусирована на том, **что делает платформа** и **как ею пользоваться**, а не на том, как она устроена изнутри.

## Статус проекта

На момент публикации документации платформа находится в состоянии **интерактивного бизнес-прототипа**. Реализована клиентская часть интерфейса с демонстрационными данными. Серверная обработка обращений, интеграция с внешними API и биллинг находятся в стадии подготовки к разработке.
