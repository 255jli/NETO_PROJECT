# Функциональное назначение модулей интерфейса

Документ описывает назначение и логику каждого раздела платформы. Для каждого модуля указано, какую задачу он решает и какие принципы заложены в его поведение.

## 1. Первые шаги (Адаптивное руководство)

- **Назначение:** навигация нового пользователя по базовым функциям.
- **Логика:** не является жёстким чек-листом. Система не идентифицирует статус пользователя (новый/возвращающийся) и не блокирует доступ к разделам. Предоставляет ненавязчивые подсказки по интеграции с внешними CRM или использованию встроенной базы.

## 2. Обзор (Конструируемый дашборд)

- **Назначение:** точка контроля ключевых показателей.
- **Логика:** пользователь самостоятельно выбирает виджеты для отображения на главной панели. Система не навязывает предустановленный набор метрик. Раскладка сохраняется между сессиями.

## 3. Голос (Управление голосовым каналом)

- **Назначение:** фиксация и анализ фактов голосовой коммуникации.
- **Логика:** отображение верифицированных данных: дата, контакт, суть запроса, итоговый статус («Записан», «Отказ», «Требуется оператор»). Субъективные оценки исключены. При выборе записи предоставляется текстовая расшифровка.

## 4. Виджет (Настройка текстового канала)

- **Назначение:** кастомизация поведенческих паттернов чат-ассистента.
- **Логика:** настройки включают не только визуальные параметры, но и сценарии поведения: порядок проявления инициативы, альтернативные способы связи, триггеры эскалации. Предусмотрен раздел с обучающими материалами по адаптации сценариев под специфику бизнеса.

## 5. Интеграции и База знаний

- **Назначение:** формирование контекстной базы ассистента.
- **Логика:** поддерживается множество методов ввода данных: структурированный опрос, свободный текст, загрузка файлов. Приоритет отдаётся данным, предоставленным пользователем. Декларируется соответствие требованиям к конфиденциальности.

## 6. CRM (Управление клиентской базой)

- **Назначение:** хранение и структурирование данных о клиентах.
- **Логика:** функционирует как самостоятельная лёгкая CRM или как буфер для синхронизации с внешними системами.
- **Ограничения:** физическое удаление карточек клиентов заблокировано для сохранения целостности истории диалогов. Неактуальные записи переводятся в статус «Прочитано» (архив).

## 7. Парсинг (Аналитика рынка)

- **Назначение:** автоматизированный мониторинг публичных ценовых предложений.
- **Логика:** отслеживание цен и ассортимента на сайтах конкурентов. В демо-среде используется сценарий розничной торговли мебелью для иллюстрации функционала.

## 8. Календарь / История взаимодействий

- **Назначение:** агрегация истории коммуникаций по конкретному контакту.
- **Логика:** отображение хронологии обращений, текстовых диалогов и собранных данных (включая cookie, при наличии согласия пользователя).

## 9. Телефония

- **Назначение:** управление номерным фондом.
- **Логика:** активация и деактивация виртуальных номеров, настройка маршрутизации звонков.

## 10. Счёт (Биллинг)

- **Назначение:** финансовый контроль и детализация расходов.
- **Логика:** предоставляется полная детализация списаний (дата, тип канала, объём, стоимость) в режиме реального времени. Абонентская плата отсутствует — оплата за фактическое потребление.

## 11. Настройки

- **Назначение:** управление параметрами аккаунта.
- **Логика:** настройка профиля организации, параметров безопасности, уведомлений и доступа к API-ключам через серверные переменные окружения.
