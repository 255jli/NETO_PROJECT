# NETO — Платформа автоматизации входящих коммуникаций

**Статус:** Интерактивный прототип (Frontend-only).  
**Цель:** Валидация UX/UI и бизнес-логики перед разработкой бэкенда.

## О продукте

NETO решает проблему потерянных звонков и обращений в малом бизнесе (МСБ), предоставляя платформу, которая объединяет голосового ассистента, чат-виджет и модуль аналитики рынка в едином интерфейсе.

## Ключевые функции

- **Голосовой помощник:** Автоматический прием звонков 24/7, транскрибация разговоров, фиксация намерений клиента.
- **Чат-виджет:** Интеллектуальный чат-бот для сайта с возможностью генерации кода для вставки.
- **Интеграции:** Подключение к популярным CRM-системам (amoCRM, Битрикс24), импорт базы знаний.
- **Аналитика конкурентов:** Мониторинг цен и ассортимента на рынке (через парсинг).
- **Встроенная CRM:** Управление базой клиентов и историей их обращений.

## Архитектура проекта

- **Тип приложения:** Фронтенд-прототип без серверной логики.
- **Данные:** Статические заглушки, расположенные в `static/js/data.js`.
- **Структура CSS:**
  - [style_1.css](file://d:\PTP\NETO_PROJECT\neto_prototype\static\css\style_1.css): Основная вёрстка (не более 800 строк).
  - [style_2.css](file://d:\PTP\NETO_PROJECT\neto_prototype\static\css\style_2.css): Стили панели управления (не более 200 строк).
  - [style_3.css](file://d:\PTP\NETO_PROJECT\neto_prototype\static\css\style_3.css): Дополнительные стили (не более 800 строк).
  - [sidebar.css](file://d:\PTP\NETO_PROJECT\neto_prototype\static\css\sidebar.css): Стили боковой панели.
- **Отметки интеграции:** Код, связанный с будущими API-вызовами, помечен комментарием `// API HOOK`.

## Технологии

- **Backend:** Python (Flask) — для роутинга и рендеринга шаблонов.
- **Frontend:** Jinja2, Vanilla JavaScript, HTML5, CSS3.
- **Данные:** Локальные моки в `static/js/data.js`.

## Локальный запуск

```bash
pip install flask
python app.py
```
