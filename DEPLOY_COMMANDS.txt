============================================================
ПУБЛИКАЦИЯ САЙТА — ПРОСТО И АВТОМАТИЧЕСКИ
============================================================
Деплой на GitHub Pages полностью автоматизирован через
GitHub Actions (.github/workflows/deploy.yml).
Вручную ничего переносить между ветками НЕ нужно.

Достаточно просто пушить изменения в main — сайт сам
соберётся и опубликуется на:
https://255jli.github.io/NETO_PROJECT/

------------------------------------------------------------
КАК ОПУБЛИКОВАТЬ ИЗМЕНЕНИЯ (выполняй по одной команде
в PowerShell, находясь в папке проекта D:\PTP\NETO_PROJECT):

git add -A
git commit -m "обновление сайта"
git push origin main

Всё! Через ~1 минуту GitHub Actions соберёт проект и
опубликует build/ на ветку gh-pages автоматически.

------------------------------------------------------------
ХОЧЕШЬ ПРОВЕРИТЬ СБОРКУ ЛОКАЛЬНО (до пуша):

.venv\Scripts\python.exe freeze_app.py

Это пересоздаст папку build/ — venv и git при этом не
затрагиваются.

------------------------------------------------------------
ПОЛЕЗНЫЕ ЗАМЕЧАНИЯ:
- Виртуальное окружение .venv НЕ удаляется и не меняется.
- Временные папки (типа gh_cache) больше не нужны — их нет.
- Ветка gh-pages обновляется автоматически через workflow,
  поэтому её не нужно переключать и чистить вручную.
- Изменяй только исходники в neto_prototype/ и делай push.
