# История изменений (Changelog)

Журнал изменений продукта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/).

## [0.2.2] — Интерфейс

### Добавлено
- Дашборд запоминает выбранный период фильтра и восстанавливает его при следующем открытии.
- Улучшено описание страницы для поисковых систем и браузеров (meta description, theme-color).

## [0.2.1] — Техническое качество

### Изменено
- Генерация событий сведена к единому источнику (`data.js`): страницы «Обзор» и «Календарь» читают одни и те же данные, расхождения между разделами исключены.

## [0.2.0] — Документация и справочные материалы

### Добавлено
- Справочные разделы документации: безопасность, тарифы, интеграции, парсинг, FAQ.
- Переработана и дополнена навигация по документации.

### Изменено
- Исправлены текстовые ошибки в продуктовой документации.
- Приведены к единому формату все документы платформы.

## [0.1.0] — Интерактивный прототип

### Добавлено
- Реализован UI/UX ключевых модулей: Обзор, Голос, Виджет, Интеграции, CRM, Парсинг, Календарь, Телефония, Счёт, Настройки.
- Конструируемый дашборд с сохранением раскладки.
- Демонстрационные данные для сценариев использования.

### Примечание
- Платформа находится в статусе интерактивного бизнес-прототипа.
- Серверная обработка, внешние API и биллинг — в стадии подготовки к разработке.
