# Каталог внешних интеграций

Документ описывает способы подключения платформы к внешним системам и формирования базы знаний ассистента.

## Способы ввода данных

Платформа поддерживает несколько методов формирования контекстной базы:

- **Структурированный опрос** — прохождение «Умного опроса» для описания компании, услуг и цен.
- **Свободный текст** — заполнение «Резюме компании» в произвольной форме.
- **Загрузка файлов** — загрузка прайс-листов и прочих документов.
- Приоритет отдаётся данным, предоставленным пользователем.

## Внешние CRM

Платформа может работать как шлюз между обращениями и внешней CRM:

- **amoCRM** — создание лидов из обращений (планируется в MVP).
- **Битрикс24** — синхронизация карточек и сделок.
- Пользователь выбирает опцию «У меня есть CRM» в разделе «Интеграции» и подключает коннектор либо вводит API-ключи.

Если внешняя CRM не используется, задействуется встроенная лёгкая CRM платформы.

## Телефония

- Подключение виртуальных номеров через SIP-транки или API виртуальных АТС (Voximplant, Mango).

## Речевые технологии (STT/TTS)

- **SaluteSpeech** или **Yandex SpeechKit** — распознавание и синтез речи.

## Диалоговая логика (LLM)

- **GigaChat API** — обработка диалоговой логики ассистента.

## Как добавить интеграцию

1. Перейдите в раздел **Интеграции**.
2. Выберите тип подключаемой системы.
3. Пройдите авторизацию через коннектор или введите API-ключ.
4. Настройте сценарий передачи данных.

> Данные доступа (API-ключи) хранятся только на сервере и не передаются в клиентский код.
