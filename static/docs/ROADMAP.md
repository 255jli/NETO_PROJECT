# Дорожная карта (Roadmap)

План развития платформы NETO. Пункты с отметкой `[x]` уже реализованы, остальные запланированы на соответствующих этапах.

## Этап 1: Прототип (Текущий)

- [x] Разработка UI/UX всех ключевых модулей.
- [x] Вёрстка страниц (Flask + Jinja2).
- [x] Подготовка моковых данных для демонстрации сценариев.
- [x] Формирование презентации для акселератора.

## Этап 2: MVP (После получения поддержки)

- [ ] Подключение API распознавания речи (STT) и синтеза (TTS).
- [ ] Интеграция с LLM для диалоговой логики.
- [ ] Реализация бэкенда на Python/Go для обработки вебхуков от телефонии.
- [ ] Базовая интеграция с amoCRM (создание лидов).

## Этап 3: Пилотирование

- [ ] Закрытие 3–5 клиентов на бесплатное тестирование.
- [ ] Сбор метрик: процент распознанных намерений, конверсия в запись.
- [ ] Доработка сценариев на основе реальных диалогов.

## Этап 4: Масштабирование

- [ ] Публичный релиз.
- [ ] Добавление конструктора сложных сценариев (no-code).
- [ ] Расширение модуля парсинга (агрегаторы, маркетплейсы).
- [ ] Расширение каталога готовых интеграций (Битрикс24, 1С).

## Метрики успеха

- Доля обращений, обработанных без участия оператора.
- Конверсия из обращения в целевое действие (запись, заявка).
- Среднее время первичной настройки аккаунта.
