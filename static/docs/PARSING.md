# Мониторинг рынка и парсинг конкурентов

Документ описывает функциональность автоматизированного мониторинга публичных ценовых предложений конкурентов.

## Назначение

Модуль **Парсинг** позволяет отслеживать цены и ассортимент на сайтах конкурентов, формируя аналитику по динамике рынка. В демо-среде используется сценарий розничной торговли мебелью для иллюстрации функционала.

## Возможности

- Добавление ссылок на сайты конкурентов.
- Указание перечня товаров для мониторинга.
- Автоматический сбор публичных данных о ценах и наличии.
- Формирование отчётов по динамике цен и наличию ассортимента.

## Как начать

1. Перейдите в раздел **Парсинг**.
2. Добавьте сайты конкурентов, за которыми нужно следить.
3. Укажите товары или категории для отслеживания.
4. Система сформирует отчёты по собранным данным.

## Текущие ограничения

- В демо-версии обрабатывается сценарий розничной торговли мебелью.
- Собираются только публичные данные; доступ к закрытым разделам сайтов не осуществляется.
- Расширение модуля (агрегаторы, маркетплейсы) запланировано на этапе масштабирования — см. [«Дорожную карту»](ROADMAP.md).
