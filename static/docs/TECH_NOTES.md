# Технические заметки

Документ фиксирует архитектурные решения, текущую реализацию демо-версии и планируемый стек для боевого контура. Предназначен для команды разработки и технических специалистов.

## Архитектура Frontend

Используется серверный рендеринг через Jinja2 (Flask).

- `base.html` — общий каркас страниц (сайдбар, хедер).
- `data.js` — генератор моковых данных для демонстрации. В продакшене будет заменён на API-вызовы к бэкенду.
- `overview.js`, `calendar.js`, `widget.js` — логика отдельных модулей дашборда.

## Текущая реализация работы с данными

Данные в таблицах (Голос, CRM) сейчас статичны или подтягиваются из `window.events`. Раскладка дашборда сохраняется в `localStorage`.

**Задача для бэкенда:**

- Создать эндпоинты `/api/events`, `/api/clients`, которые будут возвращать JSON.
- Фронтенд должен рендерить эти данные динамически вместо моков.
- Реализовать сохранение настроек и раскладки на стороне сервера.

## Планируемый стек интеграций

- **Телефония:** SIP-транки или API виртуальных АТС (Voximplant, Mango).
- **STT/TTS (распознавание и синтез речи):** SaluteSpeech или Yandex SpeechKit.
- **LLM (диалоговая логика):** GigaChat API для обработки диалогов.

## Планируемые эндпоинты

| Эндпоинт | Назначение |
|----------|------------|
| `/api/events` | Список обращений по каналам |
| `/api/clients` | Карточки клиентов CRM |
| `/api/billing` | Детализация расходов |
| `/api/parse` | Результаты мониторинга цен |

## Безопасность

- Все данные хранятся в контуре РФ (соответствие 152-ФЗ).
- Доступ к API-ключам осуществляется только через серверные переменные окружения.
- Сбор персональных данных (включая cookie) происходит только при наличии согласия пользователя.

## Производительность и надёжность ИИ

- **Задержка отклика (Latency):** Целевое значение средней задержки отклика ИИ составляет менее 500 мс. Это обеспечивает плавное и естественное взаимодействие с пользователем.
- **Подавление галлюцинаций:** Ответы ИИ формируются на основе строго заданного контекста, полученного из базы знаний и истории диалога. Используется дополнительная проверка достоверности сгенерированного текста перед его отправкой пользователю.
