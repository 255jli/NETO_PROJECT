# Project Documentation Rules (Non-Obvious Only)

- `neto_prototype/PROJECT_MANIFEST.md` местами устарел (упоминает несуществующие compliance/call-detail/chat/pricing) — сверяться с фактическими файлами `templates/dashboard/`.
- Актуальный набор страниц дашборда: overview, voice, widget, integration, crm, parsing, calendar, telephony, settings, billing, onboarding.
- `onboarding.html` — точка входа с лендинга, пункта в сайдбаре нет (осознанное решение).
- Вкладка «Настройки» (settings) переделана в «Безопасность и номера» (152-ФЗ, все номера) — название в сайдбаре не меняется.
- Презентация продукта: `Complete-NETO-presentation.pdf.txt` (текстовая выгрузка PDF) и `PROJECT_TEMPLATE.md` (шаблон для инвесторов).
