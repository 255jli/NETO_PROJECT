# Project Debug Rules (Non-Obvious Only)

- Дублирование генерации данных: события есть и в `overview.js`, и в `calendar.js` — расхождения «одинаковых» данных это известный источник багов, не дублировать источник истины.
- Жалобы на «исчезающие» виджеты: раскладка кэшируется в `localStorage` (`dashboardLayout`); сброс — кнопка «Восстановить» на странице overview.
- Виджет настройки (`widget.html`) пересоздаёт скрипт `widget.js` на лету; контейнер имеет id `neto-widget-container` и проверку на дубликат.
- Стили разнесены по нескольким CSS (`style_1/2/3.css`, `icons.css`, `sidebar.css`) + inline `<style>` в шаблонах. При поиске причины вёрстки проверяйте все.
- Нет бэкенда/API: любые ошибки данных — фронтенд (JS), логируйте в браузере, не ищите серверный лог кроме Flask dev-вывода.
