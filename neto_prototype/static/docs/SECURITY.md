# Безопасность и соответствие требованиям

Документ описывает подход платформы к защите данных, соответствию законодательству и управлению доступом.

## Соответствие законодательству

- **152-ФЗ «О персональных данных».** Все персональные данные пользователей и их клиентов хранятся в контуре РФ.
- **Хранение данных.** Размещение данных на серверах, расположенных на территории Российской Федерации.

## Защита данных пользователей

- Сбор персональных данных (включая cookie) осуществляется только при наличии согласия пользователя.
- ИИ-ассистент гарантирует конфиденциальность передаваемых данных при формировании карточки клиента.
- Запрос персональных данных (телефон, email) происходит только после предоставления базовой консультации или ответа на профильный вопрос клиента.

## Управление доступом

- Доступ к API-ключам осуществляется только через серверные переменные окружения.
- Ключи интеграций не хранятся в клиентском коде и не передаются в браузер.
- Настройки безопасности аккаунта доступны в разделе «Настройки».

## Целостность данных

- Физическое удаление карточек клиентов в CRM заблокировано для сохранения целостности истории диалогов.
- Неактуальные записи переводятся в архивный статус «Прочитано», а не удаляются безвозвратно.

## Рекомендации для пользователей

- Используйте надёжные пароли и двухфакторную аутентификацию (при наличии).
- Регулярно проверяйте детализацию расходов в разделе «Счёт».
- Не передавайте API-ключи и данные доступа третьим лицам.
