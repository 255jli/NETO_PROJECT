# Обзор

Добро пожаловать в документацию проекта NETO.

## Что такое NETO?

NETO — это интеллектуальная платформа автоматизации входящих коммуникаций. Она использует ИИ для обработки звонков и чатов, записи клиентов и интеграции с CRM.

## Основные возможности

- Обработка звонков 24/7
- Интеграция с CRM
- Аналитика и дашборды
- Настраиваемые виджеты
