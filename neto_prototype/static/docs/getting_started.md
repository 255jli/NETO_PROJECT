# Начало работы

Чтобы начать использовать NETO, перейдите в [прототип интерфейса](/dashboard/onboarding) и следуйте инструкциям.

## Создание аккаунта

Описание процесса регистрации.

### Шаг 1: Регистрация
Перейдите на главную страницу и нажмите "Войти в кабинет".

### Шаг 2: Подтверждение email
Подтвердите свой адрес электронной почты.

## Настройка ассистента

Описание процесса настройки ИИ-ассистента.

### Выбор сценария
Выберите подходящий сценарий общения для вашего бизнеса.
